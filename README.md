# おうちギルド（otetsudai-points）

ルリ・レイ・リツの3人がお手伝いや勉強をしたら「達成報告」し、親が承認すると G（ゴールド）が貯まり、
ごほうびと交換できる、家族専用のスマホアプリです。冒険者ギルドの世界観で、緊急クエスト（時限ミッション）もあります。

- iPhone / Android どちらでも動く **PWA**（ホーム画面に追加して使う Web アプリ）
- データは **Firebase**（Google のサービス）で家族全員のスマホに共有。家族で使う規模なら無料
- 企画・設計の提案書: <https://claude.ai/artifact/24nRs8vtN5xgYEqCjkffxY>

## できること（v0.1）

| 子ども | 親 |
| --- | --- |
| ギルドカード（所持 G・累計・F〜S ランク） | 承認待ちの一覧（承認・差し戻し・まとめて承認） |
| 依頼掲示板でクエストの達成報告（1日の回数制限つき） | 子どもごとの残高・ランク、ボーナス付与 |
| 緊急クエストの受注（先着1名・制限時間つき） | 緊急クエストの発令・取り消し |
| 交換所でごほうびの交換申請（G は予約され、渡した時点で確定） | クエスト・ごほうびの追加・編集（表示する子・回数上限） |
| 冒険の記録（差し戻しのひと言も見られる） | 家族のスマホを招待コードで登録 |

G が動くのは **親が承認したときだけ** です。子どもが自分で G を増やしたり、報酬額を書き換えたりできないことを、
セキュリティルールとその自動テストで確かめています。

## 2つのモード

- **お試しモード**（Firebase の設定がないとき）: その端末の中だけで動きます。上のボタンで家族5人を切り替えて全機能を試せます
- **家族共有モード**（`.env.production` か `.env.local` に Firebase の設定があるとき）: 家族全員のスマホで同じデータを使います

Firebase の準備手順は [docs/SETUP.md](docs/SETUP.md) にあります。

## 開発者向け

```bash
npm install
npm run dev               # 開発用サーバー（お試しモード）
npm test                  # ポイント計算ルールのテスト
npm run test:rules        # セキュリティルールのテスト（Java が必要）
npm run test:e2e          # 画面の動作テスト（お試しモード）
npm run test:e2e:firebase # 親と子の2台を同時に動かすテスト（Firebase エミュレーター）
npm run build             # 公開用ファイルを dist/ に作る
```

GitHub に push すると、上のテストがすべて自動で動きます（`.github/workflows/ci.yml`）。
main にマージされると、Firebase の設定が済んでいれば自動で公開されます（`.github/workflows/deploy.yml`）。

### フォルダの中身

```
src/domain/   ルール（ポイント計算・承認・交換・緊急クエスト）と初期データ。画面に依存しない
src/data/     保存先（お試しモード = localStorage / 家族共有モード = Firestore）
src/ui/       画面（kid/ = 子ども、parent/ = 親）
firestore.rules  誰が何を読める・書けるか
tests/        セキュリティルールと画面の自動テスト
docs/         手順書
```
