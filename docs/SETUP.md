# Firebase の準備（家族のスマホで使えるようにする）

所要時間は **約20〜30分** です。パソコンのブラウザで行うのがおすすめです（スマホでもできます）。
料金は無料プラン（Spark）のままで大丈夫です。クレジットカードの登録は不要です。

終わったら、**手順6** の内容を Claude に送ってください。そのあとの設定と公開は Claude が行います。

---

## 手順1. Firebase プロジェクトを作る

1. <https://console.firebase.google.com/> を開き、Google アカウントでログインします
2. 「**プロジェクトを作成**」（または「Firebase プロジェクトを始める」）を押します
3. プロジェクト名に `otetsudai-guild` など好きな名前を入れて「続行」
4. 「Google アナリティクス」は **オフ** で大丈夫です →「プロジェクトを作成」
5. 「新しいプロジェクトの準備ができました」と出たら「続行」

## 手順2. ウェブアプリを登録する

1. プロジェクトのトップ画面で **`</>`（ウェブ）** のアイコンを押します
2. アプリのニックネームに `おうちギルド` と入れます
3. 「**このアプリの Firebase Hosting も設定します**」に **チェックを入れて**「アプリを登録」
4. `const firebaseConfig = { ... }` という囲みが表示されます。**この囲みの中身をまるごとコピーして、メモ帳などに貼っておきます**（手順6で使います）
5. 残りの画面（Firebase CLI のインストールなど）は読み飛ばして「次へ」→「コンソールに進む」で大丈夫です

## 手順3. ログイン方法を有効にする

1. 左のメニューで「**構築**」→「**Authentication**」→「始める」
2. 「Sign-in method」タブで「**匿名**」を選び、「有効にする」をオンにして「保存」
   - 子どもと2人目の親は、招待コードでこの方法を使って参加します
3. もう一度「新しいプロバイダを追加」→「**Google**」を選び、「有効にする」をオン
   - 「プロジェクトのサポートメール」に自分のメールアドレスを選んで「保存」
   - 家族を最初に作る親（けいすけさん）が使います

## 手順4. データベースを作る

1. 左のメニューで「**構築**」→「**Firestore Database**」→「データベースを作成」
2. 場所（ロケーション）は **`asia-northeast1（東京）`** を選びます
   - あとから変更できないので、ここだけ注意してください
3. 「**本番環境モードで開始する**」を選んで「作成」
   - 誰が何をできるかのルールは、公開のときにアプリ側から自動で設定されます

## 手順5. 自動公開のための「鍵」を GitHub に登録する

GitHub にプログラムを入れると、自動でテストして公開されるようにするための設定です。

1. Firebase コンソールの左上の **歯車アイコン** →「**プロジェクトの設定**」
2. 「**サービス アカウント**」タブ →「**新しい秘密鍵の生成**」→「キーを生成」
   - `.json` のファイルがダウンロードされます。**このファイルは人に見せないでください**（チャットにも貼らないでください）
3. ダウンロードしたファイルをメモ帳などで開き、中身を **全部** コピーします
4. GitHub のリポジトリ <https://github.com/k09065953311-svg/otetsudai-points> を開きます
5. 「**Settings**」→ 左メニューの「**Secrets and variables**」→「**Actions**」
6. 「**New repository secret**」を押し、
   - Name: `FIREBASE_SERVICE_ACCOUNT`
   - Secret: さきほどコピーした中身を貼り付け
   - 「Add secret」
7. 登録できたら、パソコンにダウンロードした `.json` ファイルは削除して大丈夫です

## 手順6. Claude に送るもの

手順2でコピーした `firebaseConfig` の中身を、そのままチャットに送ってください。例：

```
apiKey: "AIza....",
authDomain: "otetsudai-guild.firebaseapp.com",
projectId: "otetsudai-guild",
storageBucket: "otetsudai-guild.firebasestorage.app",
messagingSenderId: "1234567890",
appId: "1:1234567890:web:abcdef"
```

- これはアプリの「住所」のようなもので、公開されても問題ない情報です（アプリの中にも入ります）
- 手順5の `.json` の中身（秘密鍵）は **送らないでください**

Claude がこの設定をリポジトリに入れると、自動で公開され、
`https://（プロジェクトID）.web.app` というアドレスで家族が使えるようになります。

## 公開後：家族のスマホに入れる

### 最初の親（けいすけさん）

1. スマホで公開されたアドレスを開きます
2. 「はじめて使う（親が Google でログインして家族を作る）」→ Google でログイン
3. 「父」を選んで「家族を作る」
4. 下のタブ「冒険者」→「スマホの登録」で、家族一人ずつ「**招待コード**」を押すと6文字のコードが出ます

### 子どもたち・お母さん

1. それぞれのスマホで同じアドレスを開きます
2. 「招待コードで参加する」→ 親のスマホに表示されたコードを入力
   - コードは24時間有効・1回限りです。失敗したら親がもう一度出せば大丈夫です

### ホーム画面に追加する（アプリのように使うため）

- **iPhone（お母さん・ルリ）**：Safari で開く → 下の **共有ボタン（□に↑）** →「**ホーム画面に追加**」
  - Chrome ではなく **Safari** で開いてください
- **Android（父・レイ・リツ）**：Chrome で開く → 右上の **︙** →「**ホーム画面に追加**」または「**アプリをインストール**」

ホーム画面のアイコンから開くと、全画面のアプリとして動きます。

### 注意

- アプリのデータを消したり、ブラウザの「履歴とサイトデータの削除」をすると、その端末はログアウトします。
  親がもう一度招待コードを出せば、同じ名前・同じ G のまま戻れます
- スマホの時計が大きくずれていると報告ができません（不正防止のため）。自動設定にしておいてください
