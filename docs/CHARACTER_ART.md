# タイトル画面のキャラ画像の作り方（写真 → アニメ調）

ChatGPT（画像生成）や Gemini に、写真を1枚付けて下の文をそのまま送ります。
**正面〜やや斜めで、顔がはっきり写った写真**を使うと、似た仕上がりになりやすいです。

## ギルドマスター（父）

```
この写真の人物をもとに、異世界ファンタジーアニメ風のキャラクターイラストを描いてください。
役柄：冒険者ギルドのギルドマスター。たくましく頼れる、面倒見のよい雰囲気。
服装：革と金属の軽い鎧、肩に深い紺色のマント、胸元に金色の留め金。
顔立ち・髪型・眼鏡など本人の特徴は写真に合わせ、少しかっこよく。表情は自信のある笑顔。
構図：胸から上、正面かやや斜め。縦長（3:4）。
背景：ランプの灯る夜のギルド酒場（ぼかし）。文字やロゴは入れない。
```

## ギルドの女将（母）

```
この写真の人物をもとに、異世界ファンタジーアニメ風のキャラクターイラストを描いてください。
役柄：冒険者ギルドの女将。酒場と受付を切り盛りする、明るく頼もしい看板女将。
服装：白いブラウス、えんじ色のスカーフ、エプロン。髪に金色のかんざし。
顔立ち・髪型など本人の特徴は写真に合わせ、少しかわいらしく。表情はやさしい笑顔。
構図：胸から上、正面かやや斜め。縦長（3:4）。
背景：ランプの灯る夜のギルド酒場（ぼかし）。文字やロゴは入れない。
```

## アプリに入れる

1. できた画像をスマホに保存する
2. 親のスマホでアプリを開く →「設定」タブ →「タイトル画面のキャラ」
3. 「画像を選ぶ」で保存した画像を選ぶ（自動で 3:4 に切り抜き・縮小されます）

- 画像は家族のデータベースに保存され、**家族のスマホでしか見られません**（公開ページには載りません）
- 「戻す」を押すと、シルエットに戻ります
- 気に入らなければ、生成し直して何度でも差し替えられます

## 写真を扱うときの注意

- 生成サービスに写真を送ると、そのサービスの規約に従って扱われます。気になる場合は、写真の代わりに「30代男性、短い黒髪、眼鏡」のような**特徴の文章だけ**で作る方法もあります
- 子どもの写真は使わないことをおすすめします
